# Деплой ReduxShop на Bothost

Бот подготовлен для Bothost: база пишется в `/app/data`, токен берётся из переменной
окружения `BOT_TOKEN`, локальный прокси на сервере автоматически отключается.
Архив для загрузки: `reduxshop-bothost.zip` в папке `reduxshop-bot`.

## Что уже настроено

- `bothost.json` — главный файл `bot.py`, язык Python, версия 3.11.
- `requirements.txt` — aiogram, aiosqlite, aiohttp-socks.
- `config.py` — читает `BOT_TOKEN`, `DATA_DIR` и другие переменные Bothost.
- База данных: `DATA_DIR/shop.db` (на Bothost это `/app/data/shop.db`),
  поэтому заказы и пользователи сохраняются между перезапусками и деплоями.
- При первом запуске автоматически создаются 193 страны-категории и товары.
- Реквизиты СБП и админ по умолчанию: `+79631969503` и ID `8147109580`.
- `.env`, `shop.db` и логи в архив не входят.

## Шаг 1. Включи загрузку из архива

1. Открой https://bothost.ru/profile.php
2. В блоке **«Интерфейс»** включи **«Загрузка бота из архива»**.
3. Сохрани настройки.

Без этого переключателя кнопки загрузки архива на дашборде не видно.
Функция доступна на тарифах Базовый и Pro.

## Шаг 2. Загрузи бота

1. Открой https://bothost.ru/dashboard.php
2. Нажми **«Загрузить из архива»**.
3. Выбери файл:

```
C:\Users\7ims (Admin)\Documents\Youtube\reduxshop-bot\reduxshop-bothost.zip
```

4. На шаге настройки укажи:
   - **Название**: `ReduxShop`
   - **Токен бота**: токен из строки `BOT_TOKEN=` в локальном `.env`
   - **Язык / шаблон**: Python или aiogram (или оставь «Авто»)
   - **Главный файл**: `bot.py`
5. Нажми **«Задеплоить»** и дождись окончания сборки.

`bothost.json` уже содержит точку входа, поэтому главный файл можно не заполнять.

## Шаг 3. Переменные окружения (необязательно)

Bothost сам передаёт `BOT_TOKEN`. Всё остальное уже имеет значения по умолчанию
в `config.py`. При желании добавь в настройках бота:

| Переменная | Значение |
|---|---|
| `ADMIN_IDS` | `8147109580` |
| `PAYMENT_DETAILS` | `+79631969503` |
| `SHOP_NAME` | `ReduxShop` |
| `SHOP_LINK` | `https://t.me/reduxstore` |
| `PAYMENT_PROVIDER_TOKEN` | пусто |
| `PROXY_URL` | пусто |

Не добавляй `PROXY_URL=http://127.0.0.1:10810` на Bothost — локального прокси там нет.
Код сам игнорирует прокси, если обнаружена среда Bothost (`BOT_ID`).

## Шаг 4. Проверка

В логах бота должно быть:

```
Автооплата выключена — работает ручная оплата по реквизитам
База данных: /app/data/shop.db
ReduxShop запущен
Run polling for bot @redux_agent
```

Затем в Telegram:

1. `/start` — появляется меню.
2. `🛍 Каталог` — страны по 12 на страницу.
3. Выбери страну — товар и цена.
4. `/admin` — админ-панель.
5. `/admin` → `📦 Товары` — товары постранично.
6. Добавь сток: `/addstock <ID>`.

## Важно: один экземпляр бота

Telegram не разрешает два одновременных polling-подключения с одним токеном.
Перед запуском бота на Bothost **останови локальный** `run.bat` / `python bot.py`.
Иначе в логах будет:

```
Conflict: terminated by other getUpdates request
```

На Bothost бот работает круглосуточно, локальный компьютер можно выключать.

## Как обновить код

На карточке бота нажми кнопку загрузки нового архива и выбери новый
`reduxshop-bothost.zip`. База в `/app/data` при обновлении сохраняется.

## Если нужен Git вместо архива

1. Создай репозиторий на GitHub/GitLab.
2. Загрузи туда файлы из `reduxshop-bot`, **кроме** `.env`, `shop.db`, `bot.log`,
   `__pycache__` и `reduxshop-bothost.zip`.
3. На Bothost: «Создать бота» → Git URL → ветка `main` → токен бота.
4. Главный файл: `bot.py`.

## Частые ошибки

| Ошибка | Причина / решение |
|---|---|
| `Conflict: terminated by other getUpdates request` | Локальный бот ещё запущен — останови его |
| `ModuleNotFoundError` | Проверь, что `requirements.txt` попал в архив |
| База пустая после деплоя | Проверь в логах путь: должен быть `/app/data/shop.db` |
| `Не найден токен бота` | В настройках бота не задан `BOT_TOKEN` |
| Бот не отвечает | Смотри логи в панели Bothost |
| Ошибка сборки архива | Убедись, что архив `.zip`, а внутри корня лежит `bot.py` |

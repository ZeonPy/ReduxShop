# ReduxShop — Telegram-бот магазина виртуальных номеров

Бот для продажи виртуальных номеров с категориями по странам, ручной оплатой по СБП,
выдачей товара администратором и поддержкой через бота.

## Что умеет

**Клиент**
- 🛍 Каталог стран: 193 страны, список разбит на страницы
- 🛒 Оформление заказа: оплата по СБП вручную
- 📦 «Мои заказы»: статусы, а после выдачи — данные номера
- 🆘 Поддержка: клиент пишет боту, админ отвечает через бота
- 💳 `/paysupport` — помощь по оплате и возвратам
- ℹ️ О магазине со ссылкой на канал

**Админ**
- 🛠 `/admin` — панель на кнопках: заказы, обращения, клиенты, товары, статистика
- 📤 Выдача товара одним нажатием (берётся из стока, клиенту уходит сообщение)
- 💰 Отметка оплаты и отмена заказа
- ✍️ Ответ клиенту по обращению или через `/chat <ID>`
- 📦 Управление товарами и стоком прямо в боте
- 🌍 При добавлении товара админ выбирает страну-категорию

## Установка и запуск

1. Установи зависимости (один раз):

```
python -m pip install -r requirements.txt
```

2. Проверь `.env` в папке `reduxshop-bot`:

```
BOT_TOKEN=токен_от_BotFather
ADMIN_IDS=твой_telegram_id
SHOP_NAME=ReduxShop
SHOP_LINK=https://t.me/reduxstore
CURRENCY=₽
PAYMENT_DETAILS=+79631969503
PAYMENT_PROVIDER_TOKEN=
PROXY_URL=http://127.0.0.1:10810
```

- `PAYMENT_PROVIDER_TOKEN` должен быть **пустым** — автооплата отключена.
- `PAYMENT_DETAILS` — номер СБП, который видит клиент.
- `PROXY_URL` нужен, только если Telegram не открывается напрямую. Если прокси
  не используется — оставь строку пустой: `PROXY_URL=`.
- Прокси должен быть запущен до старта бота.

3. Запусти:

```
run.bat
```

или

```
python bot.py
```

В консоли появится `ReduxShop запущен`. Бот работает, пока открыто это окно.

## Оплата: только СБП вручную

1. Клиент: **🛍 Каталог** → страна → товар → **🛒 Купить**.
2. Бот создаёт заказ и показывает номер СБП из `PAYMENT_DETAILS`.
3. Клиент переводит сумму и жмёт **✅ Я оплатил**.
4. Админу приходит уведомление с кнопкой **📤 Выдать товар**.
5. Админ проверяет перевод и выдаёт товар — бот отправляет данные клиенту.

Статусы: 🟡 ожидает оплаты → 🟢 оплачен → ✅ выдан (или ❌ отменён).

Автооплата Telegram Payments в коде осталась, но выключена, пока
`PAYMENT_PROVIDER_TOKEN` пустой. Включать её сейчас не нужно.

## Категории-страны

При первом запуске бот сам создаёт категории по странам и по одному товару
«Виртуальный номер <страна>» в каждой. Данные взяты с simdrop.io
(актуальны на 17.11.2026), файл `countries_data.py`:

- флаг и название страны;
- телефонный код;
- цена «от» (округлена вверх);
- количество доступных номеров на момент сбора.

Каталог показывает страны по 12 на страницу, начиная с самых популярных.
Цены и описания товаров можно менять вручную через базу или добавить свои
товары в нужную страну.

## Товары и сток

- Посмотреть товары: `/admin` → **📦 Товары** (постранично) или `/stock`
- Добавить товар: `/addproduct` → выбрать страну → название → цена → описание
- Добавить сток: `/addstock <ID>` → отправь позиции, **каждая строка — отдельный товар**
- Убрать товар из каталога: `/delproduct <ID>` или кнопка в админ-панели

Пример стока:

```
+1 555 000-00-01 | код 1234
+1 555 000-00-02 | код 5678
```

Каждая строка попадёт одному покупателю. Когда сток заканчивается, бот пишет
«нет в наличии».

## Поддержка

**Клиент:** «🆘 Поддержка» → пишет сообщение. Оно приходит админу с кнопкой
«✍️ Ответить». Дальше можно переписываться в обе стороны.

**Админ:**
- уведомление с кнопкой **✍️ Ответить**;
- `/admin` → **🆘 Обращения** → выбрать обращение;
- **✉️ Написать клиенту** из карточки клиента/заказа/обращения;
- `/chat <ID>` — написать любому клиенту;
- **✅ Закрыть** — закрыть обращение (клиент получит уведомление).

`/cancel` отменяет текущий ввод.

## Команды

| Команда | Кто | Что делает |
|---|---|---|
| `/start` | все | Главное меню |
| `/catalog` | все | Каталог стран |
| `/help` | все | Помощь |
| `/paysupport` | все | Помощь по оплате и возвратам |
| `/id` | все | Показать свой ID |
| `/admin` | админ | Админ-панель на кнопках |
| `/addproduct` | админ | Добавить товар в страну (диалог) |
| `/delproduct <ID>` | админ | Убрать товар из каталога |
| `/addstock <ID>` | админ | Добавить позиции в сток |
| `/stock` | админ | Товары и остатки |
| `/chat <ID>` | админ | Написать клиенту |
| `/cancel` | все | Отменить текущий ввод |

## Файлы

```
reduxshop-bot/
├── bot.py             — бот: меню, каталог стран, заказы, поддержка, админка
├── db.py              — SQLite: клиенты, категории, товары, сток, заказы, обращения
├── countries_data.py  — страны и цены, собранные с simdrop.io
├── config.py          — чтение .env
├── .env               — токен, админы, номер СБП, прокси
├── requirements.txt   — зависимости
├── run.bat            — запуск на Windows
└── shop.db            — база (создаётся сама при первом запуске)
```

`shop.db` хранит все заказы, сток и переписку. Не удаляй её без бэкапа.

## Важно

- Бот работает, пока запущен `run.bat`. Выключил ПК — бот недоступен.
- Токен из `.env` никому не показывай.
- При первом запуске база с демо-товарами автоматически заменяется странами simdrop.
  Это происходит только если в базе ещё нет заказов.
- Лимит Telegram: одно сообщение до 4096 символов; списки в боте постраничные.
- Для круглосуточной работы нужен постоянно включённый ПК или VPS.

## Если что-то не работает

| Проблема | Решение |
|---|---|
| `Не найден токен бота` | Заполни `BOT_TOKEN=` в `.env` |
| Ошибка соединения с api.telegram.org | Запусти прокси и проверь `PROXY_URL` в `.env` |
| `/admin` пишет «Нет доступа» | Проверь `ADMIN_IDS` (число, не username), перезапусти бота |
| Не приходят уведомления о заказах | Нажми Start у бота с админского аккаунта |
| «Нет свободного товара» при выдаче | Добавь сток: `/addstock <ID>` |
| Клиент не получил сообщение | Он не нажимал Start или заблокировал бота |
| `409 Conflict` в консоли | Бот уже запущен в другом окне — закрой лишнее |
| Бот молчит в группе | Он работает только в личных сообщениях |

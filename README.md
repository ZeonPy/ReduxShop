# ReduxShop — Telegram-бот магазина виртуальных номеров

Версия **2.2.1**. Бот продаёт виртуальные номера для приёма SMS: 193 страны,
каталог с пагинацией, ручная оплата по СБП, автовыдача через SMSFast,
поддержка клиент ↔ админ и полноценная админ-панель прямо в Telegram.

## Что нового в 2.2

- 📡 **Автовыдача через SMSFast** — после подтверждения оплаты бот сам покупает
  номер, отправляет его клиенту, ждёт SMS и присылает код.
- 💹 **Цены с учётом доставляемости** — в розницу закладывается резерв на
  номера без SMS (по умолчанию 85%).
- 📊 **Прибыль и маржа** — в статистике видно выручку, закупку, прибыль и
  фактическую доставляемость SMSFast.
- 🔁 **Синхронизация цен** — кнопка в админке подтягивает реальные закупочные
  цены SMSFast и пересчитывает розницу.
- 🧹 **Автоочистка чата** — старые экраны бота и сообщения клиента удаляются.
- 🔐 **Понятная ошибка при неверном `BOT_TOKEN`** — бот сразу пишет, что токен
  отозван или вставлен не тот, вместо длинного стектрейса.

## Что нового в 2.1

- ⚙️ **Гибкие настройки в админ-панели** — название магазина, ссылка, реквизиты,
  валюта и правила цен меняются без перезапуска бота.
- 🖼 **Управляемые баннеры** — можно заменить фото любого из 9 экранов,
  включить/выключить баннеры или вернуть стандартные.
- 🧊 **3D-аватары** для шапки магазина — три варианта в `assets/avatars/`.
- 📦 **Атомарная выдача стока** — два одновременных заказа не могут получить
  одну и ту же позицию.
- ✍️ Переписаны тексты меню, оплаты, поддержки, выдачи и админки.

## Быстрый старт

1. Установи зависимости:

```bash
python -m pip install -r requirements.txt
```

2. Создай `.env` рядом с `bot.py`:

```env
BOT_TOKEN=токен_от_BotFather
ADMIN_IDS=твой_telegram_id
SHOP_NAME=ReduxShop
SHOP_LINK=https://t.me/reduxstore
CURRENCY=₽
PAYMENT_DETAILS=+79631969503
PAYMENT_PROVIDER_TOKEN=
PROXY_URL=
SMSFAST_API_KEY=
SMSFAST_SERVICE=ot
SMSFAST_BASE_URL=https://smsfastapi.com/stubs/handler_api.php
CLEAN_CHAT=1
```

- `ADMIN_IDS` — числовые ID через запятую, не username.
- `PAYMENT_PROVIDER_TOKEN` оставь пустым для ручной оплаты по СБП.
  Если указать токен провайдера Telegram Payments, бот включит автооплату.
- `PROXY_URL` нужен только там, где Telegram недоступен напрямую.
  На Bothost прокси игнорируется автоматически.
- `SMSFAST_API_KEY` — ключ из личного кабинета SMSFast. Без него автовыдача
  выключена, но магазин продолжает работать с ручным стоком.
- `SMSFAST_SERVICE` — код сервиса: `ot` (любой другой), `tg`, `wa`, `go`,
  `lf`, `ds`, `am`, `mt`, `wx`.
- `CLEAN_CHAT=1` — бот удаляет свои прошлые экраны и сообщения клиента,
  чтобы чат не засорялся. `0` отключает очистку.

3. Запусти:

```bash
python bot.py
```

На Windows можно использовать `run.bat`. В логах появится версия, путь к базе,
правила цен и `ReduxShop 2.2.1 запущен`.

## Оплата и автовыдача

1. Клиент: **🛍 Каталог** → страна → товар → **🛒 Купить**.
2. Бот создаёт заказ и показывает реквизиты из настроек.
3. Клиент переводит сумму и нажимает **✅ Я оплатил** — это только сигнал
   админу, статус заказа пока не меняется.
4. Админ проверяет перевод и нажимает **💰 Отметить оплату**.
5. Если SMSFast настроен, бот сразу покупает номер, присылает его клиенту и
   ждёт SMS. Код приходит в этот чат автоматически.
6. Если SMSFast недоступен, бот выдаёт позицию из ручного стока.

Статусы: 🟡 ожидает оплаты → 🟢 оплачен → 🔵 номер куплен, ждём SMS →
✅ выдан (или ❌ отменён).

Если `PAYMENT_PROVIDER_TOKEN` задан, вместо ручных реквизитов бот выставляет
счёт Telegram, а после успешной оплаты запускает ту же автовыдачу.

## Каталог и цены

При первом запуске бот создаёт 193 категории-страны и по товару
«Виртуальный номер · <страна>» в каждой. Закупочные цены взяты с simdrop.io
и лежат в `app/countries.py`.

Правила розницы по умолчанию:

- закупка **до 50 ₽** — наценка ×3;
- закупка **дороже 50 ₽** — наценка ×2;
- минимальная цена — **110 ₽**;
- **доставляемость SMS 85%** — закупка делится на 0,85, чтобы сбои
  активаций не съедали прибыль;
- цена округляется вверх до красивого числа, оканчивающегося на 9:
  119, 149, 199, 249, 299, 349, 399, 499…

Примеры: Германия 32 → **119 ₽**, США 40 → **149 ₽**, Казахстан 49 → **179 ₽**,
Япония 74 → **179 ₽**, Великобритания 25 → **110 ₽**, Австрия 60 → **149 ₽**,
Бельгия 143 → **349 ₽**, Турция 204 → **499 ₽**.

Правила можно изменить: `/admin` → **⚙️ Настройки** → нужный пункт.
После изменения цен бот сам пересчитывает каталог. Цена уже созданного заказа
не меняется. Товары, добавленные админом через `/addproduct`, автоматический
пересчёт не затрагивает.

## SMSFast

1. Получи API-ключ в личном кабинете SMSFast.
2. Добавь его в переменные Bothost (`SMSFAST_API_KEY`) или в `.env`.
3. Открой `/admin` → **📡 SMSFast** и нажми **🔄 Синхронизировать цены**.
4. Проверь баланс кнопкой **💳 Проверить баланс**.

На экране SMSFast видно: статус, сервис, привязанные страны, закупку,
последнюю синхронизацию и **фактическую доставляемость** по завершённым
заказам. Если реальная доставляемость ниже 85%, подними резерв в настройках —
бот пересчитает цены.

В справочнике SMSFast нет Ниуэ, Самоа и Лихтенштейна, поэтому для них
остаётся только ручной сток. Остальные 190 стран каталога привязаны
автоматически.

Два сценария сбоя:

- **номер не купился** (нет номеров, мало баланса, неверный ключ) — заказ
  возвращается в «🟢 оплачен», админ может выдать позицию из ручного стока;
- **номер куплен, но SMS не пришла** за 15 минут — бот закрывает активацию
  (`setStatus 8`), переводит заказ в «❌ отменён» и присылает админу кнопку
  **📦 Выдать из стока**. После выдачи клиент получает товар, а неудачная
  активация остаётся в статистике доставляемости.

Оплату в обоих случаях можно вернуть вручную. Если ручного стока нет,
добавь его через `/addstock <ID>` и нажми кнопку ещё раз.

## Админ-панель

`/admin` или кнопка **🛠 Админ-панель** в главном меню.

### ⚙️ Настройки

Меняются прямо в чате, сохраняются в SQLite и применяются сразу, без рестарта:

| Настройка | Что задаёт |
|---|---|
| Название магазина | Заголовки меню, тексты, уведомления |
| Ссылка на канал | Ссылка в разделе «О магазине» |
| Реквизиты оплаты | Телефон СБП или другие реквизиты |
| Валюта | Символ валюты в ценах |
| Минимальная цена | Нижняя граница розницы |
| Порог дешёвых стран | Закупка до этой суммы идёт с первой наценкой |
| Наценка ≤ порога | Множитель для дешёвых направлений |
| Наценка > порога | Множитель для дорогих направлений |
| Доставляемость SMS | Процент успешных номеров; закупка делится на него |
| SMSFast API-ключ | Ключ провайдера для автовыдачи |
| Сервис SMSFast | Направление: `ot`, `tg`, `wa`, `go`, `lf`, `ds`, `am`, `mt`, `wx` |
| Адрес API SMSFast | Обычно `https://smsfastapi.com/stubs/handler_api.php` |

Кнопка **🔄 Пересчитать цены** применяет новые правила ко всему каталогу.
Значения из `.env` используются как база, настройки из панели имеют приоритет.

### 🖼 Баннеры

- 9 экранов: главное меню, каталог, страна, товар, оплата, заказы, поддержка,
  «О магазине», админ-панель;
- **📤 Заменить фото** — отправь картинку, и она сразу встанет на экран;
- **♻️ Вернуть стандартный** — сброс на баннер из `assets/`;
- **🔴 Выключить баннеры** — бот перейдёт на обычные текстовые сообщения.

Кастомные баннеры хранятся в базе как Telegram `file_id`, поэтому не занимают
место на диске и переживают перезапуск.

## Товары и сток

- Посмотреть товары: `/admin` → **📦 Товары** или `/stock`;
- добавить товар: `/addproduct` → страна → название → цена → описание;
- добавить сток: `/addstock <ID>` → отправь позиции, **каждая строка — отдельная**;
- убрать товар: `/delproduct <ID>` или кнопка в карточке товара.

Пример стока:

```text
+1 555 000-00-01 | код 1234
+1 555 000-00-02 | код 5678
```

Выдача защищена транзакцией `BEGIN IMMEDIATE` и блокировкой: если два клиента
оплатят одновременно, каждая позиция достанется только одному заказу.

## Поддержка

**Клиент:** «🆘 Поддержка» → пишет сообщение. Оно приходит админу с кнопкой
«✍️ Ответить». Дальше можно переписываться в обе стороны.

**Админ:**

- уведомление с кнопкой **✍️ Ответить**;
- `/admin` → **🆘 Обращения** → выбрать обращение;
- **✉️ Написать клиенту** из карточки клиента, заказа или обращения;
- `/chat <ID>` — написать любому клиенту;
- **✅ Закрыть** — закрыть обращение, клиент получит уведомление.

`/cancel` отменяет текущий ввод.

## Данные и безопасность

- База: `DATA_DIR/shop.db`, локально — `shop.db` рядом с ботом.
- В базе: клиенты, заказы, сток, обращения, настройки и `file_id` баннеров.
- `.env`, `shop.db`, `bot.log` и `__pycache__` не попадают в git и архив.
- Не удаляй `shop.db` без бэкапа: вместе с ней пропадут заказы и переписка.
- Токен бота никому не показывай; при утечке перевыпусти его в @BotFather.

## Если что-то не работает

| Проблема | Решение |
|---|---|
| `Не найден токен бота` | Заполни `BOT_TOKEN=` в `.env` |
| Ошибка соединения с api.telegram.org | Проверь прокси и `PROXY_URL` |
| `/admin` пишет «Нет доступа» | Проверь `ADMIN_IDS` (числа, не username) |
| Не приходят уведомления | Нажми Start у бота с админского аккаунта |
| «Нет свободного товара» | Добавь сток: `/addstock <ID>` |
| Клиент не получил сообщение | Он не нажимал Start или заблокировал бота |
| `409 Conflict` / `Conflict: terminated` | Бот уже запущен в другом месте |
| Бот молчит в группе | Он работает только в личных сообщениях |

Деплой на Bothost: см. [DEPLOY_BOTHOST.md](DEPLOY_BOTHOST.md).
